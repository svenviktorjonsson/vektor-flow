## Concrete failure and repair

The first current package replay exposed an existing intermittent native UI
failure. A generated hidden UI process exited with `0xC0000409` during WebView
navigation. Identical generated bytes both passed and failed; a five-launch
stress loop reproduced two failures.

Temporary tagged crash-stack instrumentation, removed before commit, resolved
the abort through the matching PDB to `HttpThreadMain` in
`native/VfOverlay/main.cpp`. WebView can connect to the loopback listener and
close the socket before sending bytes. The old code then parsed an uninitialized
request buffer; a coincidental header delimiter could place `bodyStart` beyond
the zero-byte receive boundary, turning the body length into an enormous string
allocation and triggering `SIGABRT`.

The listener now initializes its request buffer, closes and ignores zero-byte
connections before parsing, and computes the body length explicitly as a
bounded pointer difference. This changes no VKF syntax, semantics, public API,
schema, ABI, scene, renderer, or shader contract.

Post-repair hidden stress result: 10/10 generated UI launches stayed alive;
the pre-repair result was 3/5. No visible browser or UI window was used.

## Archive verification

`scripts/test-windows-portable-archive.ps1` now:

- validates the adjacent SHA-256 sidecar before extraction;
- extracts to a unique `%TEMP%` directory outside the repository;
- clears every `VKF_*` variable, restricts `PATH` to Windows system paths, and
  runs with the extraction as its working directory;
- redirects runtime and temporary state beneath the extraction;
- runs the extracted compiler inline and against the shipped hello sample;
- adds a sentinel only to the extracted `math.vkf`, proving stdlib resolution
  cannot have fallen back to the developer checkout;
- verifies the no-Python/no-C++ runtime manifest; and
- removes the temporary extraction with bounded cleanup.

`package-native-release.ps1` invokes this verifier after writing the ZIP and
checksum, so a package command cannot succeed on an untested archive.
