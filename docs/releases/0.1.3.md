# Vektor Flow 0.1.3

0.1.3 makes direct x64 numeric programs substantially faster while preserving
VKF's sub-10 ms compiler-core target.

## Filled Performance Gaps

- Refines error effects before optimization, allowing proven non-raising calls
  to use the fast lowering path.
- Inlines small straight-line numeric functions returning tuples, vectors, or
  records, including aggregate arguments and results.
- Fuses multiply/add expression trees, comparisons with branches, arithmetic
  with local stores, and repeated local loads.
- Recognizes four-lane affine numeric recurrences and emits an AVX2/FMA loop
  when the host supports it.
- Schedules the x64 SysV four-field second-order recurrence entirely in
  registers.
- Emits a minimal Linux executable shell for pure numeric programs instead of
  initializing the full native runtime import surface.
- Includes detected x64 CPU features in executable fingerprints so host-tuned
  cached artifacts are never reused under an incompatible feature set.
- Adds native VKF regression tests for optimized vector and record recurrence
  results.

## Verification Contract

- 298 native VKF tests; zero failures required on every release target.
- 59 guide programs, each compiled 100 times from fresh paths and run 100 times
  in fresh processes on Windows x64, Linux x64, and macOS ARM64.
- Seven-language Linux comparison over 100 measured compiles and 100 measured
  fresh-process runs for every published case.
- Exact outputs, source/compiler hashes, all samples, tool versions, OS,
  architecture, and CPU are retained in the proof artifacts.
- The fixed 10-million-operation container workload remains unchanged.

## Native Product Boundary

Included: `math`, `stat`, `random`, `time`, `io`, `collections`, `errors`,
`system`, `process`, and `regex`.

Excluded: `physics`, `ui`, and `symbolic`. They remain absent rather than
partial or backed by compatibility code.

VKF remains unsupported experimental software. Do not run untrusted programs
or use this release for production work.
