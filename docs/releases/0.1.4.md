# VKF 0.1.4 — Standard Kernels And Numeric Lowering

VKF 0.1.4 replaces the previous ad-hoc language comparison with published,
recognizable algorithms and improves the direct x64 backend where those kernels
exposed avoidable work.

## What changed from 0.1.3

- The comparison suite now uses spectral norm, fannkuch-redux, and n-body,
  adapted from the Computer Language Benchmarks Game at fixed small, medium,
  and large scales.
- Exact VKF, C, Rust, Zig, Go, Julia, and Python sources are materialized and
  linked from the report. Numeric output must contain exactly one finite value;
  missing or duplicate output fails verification.
- C, Rust, and Zig join VKF in raw in-process kernel timing. Fresh-process
  compile and runtime remain separate measurements.
- Fixed-vector indexing records integer type evidence. Dominating constant
  bounds and canonical nonnegative induction remove only checks proven
  redundant; unproven and fractional indices retain runtime errors.
- Long numeric expressions lower directly through x64 registers instead of
  spilling every intermediate stack value.
- Proven fixed-vector indices remain in integer registers across adjacent hot
  expressions and updates.
- Parameters in numeric-scalar functions become constants only when every
  direct call supplies the same literal and the parameter is not mutated or
  aliased by a fixed-vector update. Aggregate returns remain unchanged.
- The scalar recurrence optimizer preserves branch behavior and numeric order.
- Linux minimal numeric output writes exactly one result line.

## Verification contract

Release publication requires all of the following from the tagged source:

- 301 native VKF tests on Windows x64, Linux x64, and macOS ARM64;
- every documented program compiled 100 times and run 100 times on all three
  release targets with exact output and source/compiler hashes;
- 100-run seven-language comparison on Linux x64;
- direct compiler lowering with no Python, C++ compiler, assembler, linker, or
  compatibility fallback at user compile time or runtime.

The historical 20,000-operation scalar engineering gate remains under 10 ms
mean compiler-core time and 500 microseconds mean raw runtime. Those limits do
not apply to the larger standard kernels.

## Interpretation

Results are evidence for the exact code, host, toolchains, and work counts in
the report—not a claim that VKF is universally faster than another language.
See [benchmark policy](../performance-benchmarks.md) for provenance and limits.

Native library scope remains `math`, `stat`, `random`, `time`, `io`,
`collections`, `errors`, `system`, `process`, and `regex`. `physics`, `ui`, and
`symbolic` remain excluded rather than shipping partial implementations.
