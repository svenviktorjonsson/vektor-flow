# Vektor Flow 0.1.2

0.1.2 makes mutation and error propagation explicit, fills structural-update
gaps, and strengthens release proof.

## Filled Gaps

- `name:value` declares only; `.name:value` updates only.
- Duplicate declarations and updates of missing names are compile errors.
- Compound mutation requires dot syntax, such as `.total +:3`.
- Declarations and updates return the stored value.
- Function parameters count as existing bindings.
- Numeric compound updates distribute through compatible structural leaves and
  preserve incompatible metadata such as strings and bits.
- `!` raises only an error type or error value. It is never factorial.
- `Error!` constructs and raises a default typed error; `Error("message")!`
  raises a message-bearing value; `expression!?` catches it in `$`.
- `vkf -t` now checks expected compile failures natively.
- `vkf -v` prints the embedded release identity; proof rejects a compiler that
  does not match package version.
- Landing documentation is shorter; full numbered reference moved to
  `docs/language-guide.md`.

## Verification Contract

- 296 native VKF tests; zero failures required.
- 59 guide programs, each compiled 100 times from fresh paths and run 100 times
  in fresh processes on Windows x64, Linux x64, and macOS ARM64.
- Exact stdout/stderr, exit code, source SHA-256, compiler SHA-256, all timing
  samples, tool version, OS, architecture, and CPU retained.
- Fixed 10-million-operation container workload; no timing calibration.
- Seven-language Linux comparison: VKF, C, Rust, Zig, Go, Julia, and Python.
  Matched and idiomatic cases are labeled separately; Python uses NumPy/SciPy
  and Julia uses standard linear algebra where suitable.

## Native Product Boundary

Included: `math`, `stat`, `random`, `time`, `io`, `collections`, `errors`,
`system`, `process`, and `regex`.

Excluded: `physics`, `ui`, and `symbolic`. They are absent, not partial and not
backed by Python/C++ compatibility code.

VKF remains unsupported experimental software. Do not run untrusted programs
or use this release for production work.
