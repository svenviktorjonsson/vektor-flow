# Vektor Flow 0.4.0

## Native visual applications

VKF 0.4.0 adds the compiled Windows visual runtime. A built application embeds
its retained scene, the transparent WebView2 overlay, static HTML/CSS assets,
and the WebGPU renderer. Application behavior and event handling remain
compiled VKF; C++ is restricted to the thin operating-system/WebView2 adapter.

Frames can combine ordinary `add(...)` scene operations with a separately
loaded static HTML document. HTML-named components, recursive `id` lookup,
owner event queues, default frame chrome, dragging, resizing, and
`prevent_default()` use the same retained runtime whether the tree came from
VKF or HTML. Authored UI files need no application JavaScript.

## Scenes and capture evidence

The release tree contains 20 short, complete 2D and 3D scene examples. They
cover line and scatter plots, dense point clouds, vector fields, surfaces,
symbolic constraints, lighting, shadows, reflections, transparency, tinted
glass, textures, UI controls, selection, animation, and rigid-body geometry.

Each example is paired with a hash-locked full-compositor PNG captured in a
hidden Edge session. The material gallery additionally includes renderer-only
captures and a playable interaction GIF, proving the HTML/CSS overlay and
WebGPU canvas independently and together.

## Release and performance evidence

- The Windows compiler and generated applications require no Python, Node,
  compiler, assembler, or separate linker at runtime.
- The release-host link-map gate rejects C++ UI semantic objects, while the PE
  and module gates reject bundled or loaded non-system runtime libraries.
- The correctness-gated large-scene study completes all seven applicable GPU
  lanes and keeps all five comparable ratios strictly below `1.5x`.
- The retained one-million-point cloud study records pacing, GPU completion,
  cold-start, correctness, and buffer-retention evidence. It is a diagnostic
  indicator only and deliberately carries no `<1.5x` release ratchet.
- The established core, linear-algebra, and symbolic comparisons are rerun by
  the release workflow with the 0.4.0 compiler before publication.

## Compatibility and scope

VKF remains an unsupported experimental language with unstable APIs and
syntax. Windows x64 carries the visual runtime in 0.4.0. Linux x64 and macOS
Apple Silicon keep their native compiler and scientific-library packages; the
Windows WebView2 UI adapter is not advertised on those platforms.
