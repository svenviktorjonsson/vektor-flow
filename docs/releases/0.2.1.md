# VKF 0.2.1 — Exact Output Proof And Faster Integer Pipes

VKF 0.2.1 fixes two native-code correctness gaps found while strengthening the
release proof, then optimizes the same compact vector-pipe forms used by the
language guide and Fannkuch benchmark. It adds no runtime dependency.

## Correctness

- Consecutive compound updates inside a function preserve an established
  fixed-vector type when an intermediate expression is otherwise inferred as
  `any`. The 10-million-operation container example now returns its required
  `10000000` result instead of silently reusing one vector element.
- macOS ARM64 indexed fixed-vector loads and stores now convert native integer
  locals through the numeric value ABI. Integer bits are no longer
  reinterpreted as floating-point values in range-pipe assignments.
- The documented-program verifier checks committed exact stdout for the two
  high-value regression examples as well as repeated-run byte stability. A
  consistently wrong output can no longer pass merely because it is stable.

## Native Optimizer

- Indexed assignments whose onward result is immediately discarded bypass the
  temporary value round trip introduced by pipe lowering.
- Fall-through-only continuation labels are removed before backend pattern
  recognition.
- Compact fixed-vector copy and bounded-shift pipes recover dedicated integer
  lowering without requiring manual counter loops.
- Proven two-pointer prefix reversals retain both indices in registers across
  the loop and write them back only on exit. Their source-level temporary is
  committed once per reversal rather than once per swap.
- Scalar fields in structured locals, such as `result.checksum`, are now
  eligible for integer registers. Only storage proven to be indexed stays
  memory-backed. This makes compact structured code fast without flattening
  it into unrelated variables.
- Proven constant indices in unrolled small-vector interaction kernels use
  direct frame addresses instead of reconstructing indexed addresses.
- Statically unrolled three-component interactions keep adjacent `x` and `y`
  lanes packed through subtraction, dot products, velocity updates, and
  stores; `z` remains scalar. This reduces N-body work without changing its
  numerical result.
- The policy tuner seeds interaction-heavy small-vector programs with a safe
  policy selected by the exhaustive landscape for that program shape, then
  validates it against the scalar result. When no tuning budget remains, it
  falls back to the conservative validated policy instead of unvalidated
  aggressive code.
- Fannkuch declares its exact `int -> int` contract. The committed release
  comparison is regenerated from the final compiler and is the authoritative
  performance result.

## Verification

- The native suite contains **333 passing VKF tests**.
- Every documented program is compiled and executed 10 times on Windows x64,
  Linux x64, and macOS ARM64 with exact output checks.
- The controlled Linux comparison performs 100 fresh compilations and 1,000
  raw runs for spectral norm, Fannkuch, and N-body. Each fresh VKF compilation
  receives an 80 ms optimizer-search budget, and the complete search remains
  included in reported VKF compile time.
- `physics`, `ui`, and `symbolic` remain excluded rather than shipping partial
  or compatibility implementations.

The installed compiler continues to emit PE, ELF, or Mach-O executables
directly. Compiling and running VKF requires no Python, C++ compiler, assembler,
or separate linker.
