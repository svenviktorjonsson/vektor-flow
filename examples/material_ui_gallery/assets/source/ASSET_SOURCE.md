# Stanford Bunny source

`bun_zipper.ply` is the full-resolution zippered Stanford Bunny surface
reconstruction published by the Stanford Computer Graphics Laboratory.

- Source: <https://graphics.stanford.edu/data/3Dscanrep/>
- Archive: <https://graphics.stanford.edu/pub/3Dscanrep/bunny.tar.gz>
- Archive SHA-256: `a5720bd96d158df403d153381b8411a727a1d73cff2f33dc9b212d6f75455b84`
- File SHA-256: `b1acc63bece78444aa2e15bdcc72371a201279b98c6f5d4b74c993d02f0566fe`
- Topology: 35,947 vertices and 69,451 triangles
